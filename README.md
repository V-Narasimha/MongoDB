# MongoDB Practice Repository

This repository contains basic MongoDB examples and practice programs for learning MongoDB operations such as creating databases, collections, inserting documents, updating records, deleting data, and querying documents.

## 📌 Features

- Create Database and Collection
- Insert One / Insert Many
- Find Documents
- Update One / Update Many
- Delete One / Delete Many
- Sorting and Limiting Results
- Basic MongoDB Queries
- Beginner Friendly Examples
